1. Win + R and type powershell then press Enter

2. Copy + Paste this command line >
cd "C:\Users\User\Desktop\Biometrics Attendance Generator"
py export_logs.py

3. Open attendance.csv

4. Done

Notes:
- if it's not working, check the IP address of the Biometrics. Open export_logs.py with Notepad. Change the IP address and save then run again.
- if generating again, make sure attendance.csv is closed before running the command.
- if you need to generate attendance from previous months or years, inside export_logs.py, change the number in MONTH_TO_EXPORT = ""
- you can use the shortcut made in Desktop called "DTR Generator" if you don't want to go powershell. It will automatically run the script.
- don't rename or delete anything in the folder (except attendance.csv, it would just generate a new after running the script).
- don't move the files or the folder itself anywhere unless you know how to change paths in the script.
